OnePreview
ホームヘルプサポートプライバシー

macOS、iOS、iPadOS の Quick Look 拡張機能

Markdown を Quick Look で読み、そのまま他の開発者ファイルも確認。

OnePreview は GitHub 風 Markdown をシステムプレビュー内で表示し、シンタックスハイライト、Mermaid、KaTeX に対応します。エディタを開く前に、コード、構造化データ、ZIP、フォルダ、SQLite も確認できます。

Markdown プレビュー

Finder、ファイル App、Quick Look で読みやすい Markdown。

GitHub 風レンダリング

見出し、表、タスクリスト、コードブロック、アラート、ドキュメント向け Markdown をフルエディタなしでプレビュー。

MDX、TextBundle、TextPack

一般的な Markdown パッケージ形式を、フォルダやアーカイブではなく読みやすい文書として開きます。

Mermaid と KaTeX を内蔵

同梱アセットで図表、チャート、数式を表示し、一般的な Markdown 文書をオフラインでも扱えます。

表示とソースを切り替え

正確な記法を確認したい時は、HTML プレビューと元の Markdown ソースを切り替えられます。

Markdown だけではありません

毎日確認する開発者ファイルを 1 つの拡張機能で。

ソースコード

Swift、Python、JavaScript、TypeScript、C、C++、Objective-C、Rust、Go、Ruby、Java、Shell、Assembly など。

構造化データ

JSON、JSONL、YAML、XML、CSV、TSV、TOML、ENV、Apple property list などのテキストデータ形式。

アーカイブとフォルダ

ZIP の内容やフォルダ一覧を、サイズ、更新日、見やすい構造で表示。

SQLite データベース

データベースツールを起動せずに、テーブル、ビュー、インデックス、列、サンプル行を確認。

対応形式： Markdown、MDX、TextBundle、TextPack、JSON、JSONL、YAML、XML、CSV、TSV、TOML、ENV、SQLite、Swift、Python、JavaScript、TypeScript、C、C++、Objective-C、Rust、Go、Ruby、Java、Shell、Assembly、ソースコード、プレーンテキスト、ログ、フォルダ、ZIPアーカイブ、Appleプロパティリスト（plist）。

アカウント不要一度インストールすればシステムプレビューで使えます。
ローカルプレビューファイルは Apple のプレビュー機構内で扱われます。
無料アプリApp Storeで利用できます。

ワークフロー

実際の Quick Look 習慣のために設計。

Finder に留まる

macOS でスペースバーを押すだけで、フルエディタを開かずに対応ファイルを確認。

iPhone と iPad でも利用

ファイル App やシステム Quick Look を使う App で利用できます。

設定ガイド付き

OnePreview を一度開き、拡張機能を有効化し、トラブルシューティング手順を確認できます。
