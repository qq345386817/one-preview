Markdown プレビュー

MacのFinderとiPhone／iPadのファイルAppから読みやすいMarkdownを表示。

GitHub 風レンダリング

見出し、表、タスクリスト、コードブロック、アラート、ドキュメント向け Markdown をフルエディタなしでプレビュー。

MDX、TextBundle、TextPack

一般的な Markdown パッケージ形式を、フォルダやアーカイブではなく読みやすい文書として開きます。

Mermaid と KaTeX を内蔵

同梱アセットで図表、チャート、数式を表示し、一般的な Markdown 文書をオフラインでも扱えます。

表示とソースを切り替え

正確な記法を確認したい時は、HTML プレビューと元の Markdown ソースを切り替えられます。

Markdown だけではありません

毎日確認する開発者ファイルを 1 つの拡張機能で。

ソースコード

Swift、Python、JavaScript、TypeScript、C、C++、Objective-C、Rust、Go、Ruby、Java、Shell、Assembly など。

構造化データ

JSON、JSONL、YAML、XML、CSV、TSV、TOML、ENV、Apple property list などのテキストデータ形式。

アーカイブとフォルダ

ZIP/TAR.GZ の内容やフォルダ一覧を、サイズ、更新日、見やすい構造で表示。

SQLite データベース

データベースツールを起動せずに、テーブル、ビュー、インデックス、列、サンプル行を確認。

対応形式： Markdown、MDX、TextBundle、TextPack、JSON、JSONL、YAML、XML、CSV、TSV、TOML、ENV、SQLite、Swift、Python、JavaScript、TypeScript、C、C++、Objective-C、Rust、Go、Ruby、Java、Shell、Assembly、ソースコード、プレーンテキスト、ログ、フォルダ、ZIP/TAR.GZアーカイブ、Appleプロパティリスト（plist）。

アカウント不要一度インストールすれば、ファイルをローカル表示できます。
ローカルプレビューファイルは Apple のプレビュー機構内で扱われます。
無料アプリApp Storeで利用できます。

ワークフロー

実際の Quick Look 習慣のために設計。

Finder に留まる

macOS でスペースバーを押すだけで、フルエディタを開かずに対応ファイルを確認。

iPhone と iPad でも利用

ファイルAppで対応ファイルを長押しし、「このアプリで開く」からOnePreviewを選択します。通常のタップではAppleの内蔵プレビューが使われる場合があります。

設定ガイド付き

MacではQuick Look拡張機能を有効にします。iPhone／iPadではファイルAppの「このアプリで開く」からOnePreviewを選びます。

設定ヘルプを読む

設定とファイルプレビューガイド

Quick Look 拡張機能を有効にする

インストール後に OnePreview を一度開き、システムの拡張機能設定で有効にします。

プライバシーとファイル処理を確認

ファイルは Apple のシステムプレビュー機構を通じてローカルでプレビューされます。

正しく表示されないファイルを報告

ファイル種類、OS バージョン、短い再現メモを送ってください。
