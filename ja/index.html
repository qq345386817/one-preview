OnePreview 1.5.1 の機能

Markdown フォルダを閲覧・検索して PDF に

フォルダの閲覧と検索

OnePreviewでフォルダを開き、文書を切り替え、Markdownの相対リンクや見出しへ移動できます。戻る・進むで閲覧履歴をたどり、同じセッション内では表示モードと読書位置を復元します。許可したフォルダ内のファイル名と読めるテキストを検索。走査上限に達すると一部の結果であることを表示し、検索索引はディスクに保存しません。

しおり付き PDF に結合

アプリで開いたフォルダとサブフォルダから、最大20件の.mdまたは.markdownを選択。順序を調整してプレビューし、文書ごとのしおり付きA4 PDFに書き出せます。上限は100ページ、64 MiB。アクセス権とサイズ制限の範囲でローカルの相対パス画像を埋め込み、欠落・リモート・範囲外の画像はプレースホルダーで示します。元のファイルは変更しません。

Markdown の表示設定

システム連動・ライト・ダーク・暖色の紙のテーマ、フォント、文字サイズ、余白、読書幅を選べます。

フォルダの閲覧ガイドPDF の結合手順

Markdown プレビュー

Markdownを、 読みやすい文書に。

GitHub 風レンダリング

見出し、表、タスクリスト、コードブロック、アラート、ドキュメント向け Markdown をフルエディタなしでプレビュー。

MDX、TextBundle、TextPack

一般的な Markdown パッケージ形式を、フォルダやアーカイブではなく読みやすい文書として開きます。

Mermaid と KaTeX を内蔵

同梱アセットで図表、チャート、数式を表示し、一般的な Markdown 文書をオフラインでも扱えます。

表示とソースを切り替え

正確な記法を確認したい時は、HTML プレビューと元の Markdown ソースを切り替えられます。

Markdown だけではありません

文書を読む。データやアーカイブの内容を確認する。

ソースコード

Swift、Python、JavaScript、TypeScript、C、C++、Objective-C、Rust、Go、Ruby、Java、Shell、Assembly など。

構造化データ

JSON、JSONL/NDJSON、YAML、XML、CSV、TSV、TOML、ENV, INI, properties、Apple property list などのテキストデータ形式。

アーカイブとフォルダ

ZIP/TAR.GZ/TGZ の内容やフォルダ一覧を、サイズ、更新日、見やすい構造で表示。

SQLite データベース

データベースツールを起動せずに、テーブル、ビュー、インデックス、列、サンプル行を確認。

対応形式： Markdown、MDX、TextBundle、TextPack、JSON、JSONL/NDJSON、YAML、XML、CSV、TSV、TOML、ENV, INI, properties、SQLite、Swift、Python、JavaScript、TypeScript、C、C++、Objective-C、Rust、Go、Ruby、Java、Shell、Assembly、ソースコード、プレーンテキスト、ログ、フォルダ、ZIP/TAR.GZ/TGZアーカイブ、Appleプロパティリスト（plist）。

OnePreview App · Markdown → PDF

アプリでMarkdownを読み込み、レポートPDFに

Mac・iPhone・iPadのOnePreviewで「ファイル > ツール > MarkdownをPDFに変換」から.mdまたは.markdownを読み込みます。実際のA4 PDFを確認してから保存できます。表、コードの折り返し、Mermaid図、KaTeX数式に対応。PDF書き出しはメインアプリの機能で、Finder Quick Look内では使えません。ファイルを編集する機能ではありません。

アプリのPDF操作手順を見る

Markdown → PDF

ブラウザで無料のMarkdown PDF変換

プロジェクトの週報、技術文書、引き継ぎ資料をA4のPDFに。このWeb変換ツールはOnePreviewアプリなしでも単独で使えます。

インストールも文書のアップロードも不要

.md・.markdownファイルを開くか、内容を貼り付けてください。文書と選択した画像は現在のブラウザセッション内で処理します。アカウントやアプリは不要です。

表、Mermaid図、数式を保持

A4のページ分割、表の見出し、折り返したコード、Mermaid図、KaTeX数式を確認してから「印刷 / PDFとして保存」で出力できます。

Markdownを無料でPDFに変換

ワークフロー

実際の Quick Look 習慣のために設計。

Finder に留まる

macOS でスペースバーを押すだけで、フルエディタを開かずに対応ファイルを確認。

iPhone と iPad でも利用

ファイルAppで対応ファイルを長押しし、「このアプリで開く」からOnePreviewを選択します。通常のタップではAppleの内蔵プレビューが使われる場合があります。

設定ガイド付き

MacではQuick Look拡張機能を有効にします。iPhone／iPadではファイルAppの「このアプリで開く」からOnePreviewを選びます。

Macで使うエディタを選択

OnePreviewやFinderのQuick Lookから、元のファイルを好みのエディタで開けます。macOSのデフォルトを変えず、拡張子ごとに選択を記憶できます。

設定ヘルプを読む
アカウント不要一度インストールすれば、ファイルをローカル表示できます。
ローカルプレビュー文書は読み取り専用で、端末内で処理します。
無料アプリApp Storeで利用できます。

設定とファイルプレビューガイド

Quick Look 拡張機能を有効にする

インストール後に OnePreview を一度開き、システムの拡張機能設定で有効にします。

プライバシーとファイル処理を確認

ファイルは Apple のシステムプレビュー機構を通じてローカルでプレビューされます。

正しく表示されないファイルを報告

ファイル種類、OS バージョン、短い再現メモを送ってください。
