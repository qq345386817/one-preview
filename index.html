macOS, iOS and iPadOS Quick Look extension

Quick Look Markdown files, then keep going.

OnePreview renders GitHub-style Markdown with syntax highlighting, Mermaid diagrams and KaTeX math directly in the system preview flow. It also previews source code, structured data, ZIP archives, folders and SQLite databases before you open an editor.

Markdown Preview

Readable Markdown from Finder, Files and Quick Look.

GitHub-style rendering

Preview headings, tables, task lists, fenced code blocks, alerts and documentation-style Markdown without opening a full editor.

MDX, TextBundle, TextPack

Open common Markdown package formats as readable documents instead of plain folders or archives.

Mermaid and KaTeX built in

Render diagrams, charts and math formulas using bundled assets, so common Markdown documents work offline.

Rendered or raw

Switch between the readable HTML preview and the original Markdown source whenever you need to inspect exact syntax.

Beyond Markdown

One extension for the developer files you inspect every day.

Source code

Swift, Python, JavaScript, TypeScript, C, C++, Objective-C, Rust, Go, Ruby, Java, shell scripts, Assembly, and more.

Structured data

JSON, JSONL, YAML, XML, CSV, TSV, TOML, ENV, Apple property lists, and other text-based data formats.

Archives and folders

Browse ZIP archive contents and folder listings with file sizes, modification dates and clear structure.

SQLite databases

Inspect tables, views, indexes, columns and sample rows without running a database tool first.

Workflow

Designed for real Quick Look habits.

Stay in Finder

Press Spacebar on macOS to inspect supported files without launching a full editor.

Works on iPhone and iPad

Use the Files app or any app that opens system Quick Look previews.

Setup guidance included

Open OnePreview once, enable the extension, and keep troubleshooting steps close at hand.
