In OnePreview 1.5.1

Read, search and export a Markdown folder

Folder reading and search

Open a folder in OnePreview, switch between files, follow relative Markdown links and headings, and move back through your reading history. Reading mode and position are remembered within the current session. Search file names and readable text in the authorized folder; scan limits may return partial results. No search index is saved to disk.

One PDF with bookmarks

In the app, select up to 20 .md or .markdown documents from an open folder and its subfolders. Reorder them, preview the result and export one A4 PDF with a bookmark for each document. The limit is 100 pages and 64 MiB. Local relative images are embedded within access and size limits; missing, remote or out-of-folder images show placeholders. Source files remain unchanged.

Markdown reading appearance

Choose a system, light, dark or warm-paper theme, fonts, text size, spacing and reading width.

OnePreview App · Markdown → PDF

Export a Markdown PDF report in the app

In OnePreview on Mac, iPhone or iPad, choose Files > Tools > Markdown to PDF and import a .md or .markdown file. Check the actual A4 PDF, then save it. Tables, wrapped code, Mermaid diagrams and KaTeX math are supported. PDF export is in the main app, not Finder Quick Look. OnePreview is a viewer, not an editor.

Workflow

Designed for real Quick Look habits.

Stay in Finder

Press Spacebar on macOS to inspect supported files without launching a full editor.

Works on iPhone and iPad

In Files, long-press a supported file, choose Open With, then select OnePreview. A normal tap may use Apple’s built-in preview.

Setup guidance included

Enable the Quick Look extension on Mac. On iPhone and iPad, use Open With > OnePreview from Files.

Choose your editor on Mac

Open the original file in your preferred editor from OnePreview or Finder Quick Look. Remember a choice for each file type without changing macOS defaults.
