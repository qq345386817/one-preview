Markdown Preview

Readable Markdown in Finder on Mac and from Files on iPhone and iPad.

GitHub-style rendering

Preview headings, tables, task lists, fenced code blocks, alerts and documentation-style Markdown without opening a full editor.

MDX, TextBundle, TextPack

Open common Markdown package formats as readable documents instead of plain folders or archives.

Mermaid and KaTeX built in

Render diagrams, charts and math formulas using bundled assets, so common Markdown documents work offline.

Rendered or raw

Workflow

Designed for real Quick Look habits.

Stay in Finder

Press Spacebar on macOS to inspect supported files without launching a full editor.

Works on iPhone and iPad

In Files, long-press a supported file, choose Open With, then select OnePreview. A normal tap may use Apple’s built-in preview.

Setup guidance included

Enable the Quick Look extension on Mac. On iPhone and iPad, use Open With > OnePreview from Files.

Read setup help

Setup and file preview guides

Enable the Quick Look extension

Open OnePreview once after installation, then enable it in system extension settings.

Understand privacy and file handling

Files are previewed locally through Apple system preview mechanisms.

Report a file that does not preview correctly

Send the file type, OS version and a short reproduction note.
