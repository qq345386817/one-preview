# Authentic App Previews

These are unchanged, full-window captures of OnePreview 1.4.5 displaying the project's localized Markdown sample. They come from the 2026-10-15 native App Store screenshot run (`raw/mac/<locale>/01-markdown.png`) and are used as website product images, not as review/test evidence. The images retain their actual dark appearance, native window chrome and complete document area. They do not represent the web PDF converter and do not claim to show all features added in 1.4.6.

Each landing page uses the matching document and UI language. Website locale `en` maps to capture `en-US`, `de` to `de-DE`, and `fr` to `fr-FR`; the other locale names match directly. Each original PNG is 1180 x 820. Do not stretch, crop, paint over, recreate the window or replace it with an invented mockup. Future screenshots should use only intentionally public sample content.
