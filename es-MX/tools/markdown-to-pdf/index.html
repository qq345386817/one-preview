    Reportes, documentación y notas de entrega

    Usa el convertidor para un reporte semanal con una tabla de avance, notas técnicas con código y fórmulas o documentación de entrega con un diagrama Mermaid. El ejemplo descargable reúne estas funciones en un reporte.

    ¿Cómo guardo el PDF?

    Usa Imprimir / Guardar PDF y selecciona el destino PDF del navegador o del sistema. En iPhone y iPad, comparte o guarda el PDF desde la vista de impresión del sistema. Esta vista muestra el contenido; los encabezados adicionales y el papel se configuran en el diálogo de impresión.

    ¿Cuáles son los límites?

    Un formato A4, hasta 500 KB de Markdown y 100 páginas. Las filas demasiado altas o los elementos que no se pueden dividir generan un aviso en vez de un PDF recortado. También se reportan imágenes faltantes, diagramas o fórmulas inválidos. Esta primera versión no incluye componentes MDX, scripts personalizados, TextBundle ni TextPack.

    ¿Este convertidor de Markdown a PDF es gratis?

    Sí. La herramienta web actual es gratuita y funciona sin cuenta ni app OnePreview. El texto y las imágenes elegidas permanecen en la sesión del navegador y no se cargan a un servidor de conversión.

    ¿Puedo exportar diagramas Mermaid y fórmulas a PDF?

    Sí. Escribe el diagrama en un bloque de código mermaid y las fórmulas con sintaxis compatible con KaTeX. Revisa la vista antes de imprimir. Si no se puede generar un diagrama o fórmula, se muestra un aviso y se conserva el texto original.

    ¿Cómo continúan las tablas en la siguiente página?

    Las tablas Markdown estilo GitHub se distribuyen en páginas A4 y repiten el encabezado. El código se ajusta al ancho disponible. Si una fila es más alta que una página o el contenido es demasiado ancho, se muestra un aviso. Acorta la fila o reduce las columnas y vuelve a intentarlo.

    ¿Por qué faltan imágenes en mi PDF?

    Elige las imágenes locales referenciadas en el Markdown con los nombres de archivo correspondientes. Las imágenes remotas no se cargan automáticamente. Hasta 16 imágenes, de máximo 5 MB cada una y 20 MB en total; las faltantes o ilegibles generan un aviso.

    ¿Necesitas ver archivos locales?

    OnePreview para Mac, iPhone y iPad muestra Markdown y archivos de desarrollo en tu dispositivo. Esta herramienta web funciona sin la app.
