Markdown을 공유하기 좋은 PDF로.

페이지 번호, 반복되는 표 머리글과 읽기 쉬운 코드를 갖춘 깔끔한 A4 레이아웃입니다. 각 페이지를 확인한 뒤 PDF로 저장하세요.

![차트](images/chart.png)를 사용하면 chart.png도 선택하세요. 원격 이미지는 불러오지 않습니다. 최대 16개, 이미지당 5 MB까지 가능합니다.

예제 준비 중…

    A4 용지와 100% 배율을 선택하세요. 브라우저 머리글과 바닥글은 끄세요. 보고서에 자체 페이지 번호가 포함되어 있습니다.

    문서와 선택한 이미지는 현재 브라우저 세션에만 남습니다. 이 웹사이트에 업로드하거나 저장하지 않습니다.

    읽고 복사할 수 있는 보고서

    PDF는 문서 스크린샷이 아닌 텍스트를 유지합니다. 표준 Markdown, GitHub 스타일 표, 코드 블록, Mermaid 다이어그램과 KaTeX 수식을 지원합니다. 긴 표는 각 페이지에 머리글을 반복하며 긴 코드는 너비에 맞춰 줄바꿈합니다.

    Markdown 예제 다운로드로 같은 보고서를 다른 작업 환경에서도 사용해 보세요.

    주간 보고서, 기술 문서와 인수인계 자료에 활용

    진행 상황 표가 있는 주간 보고서, 코드와 수식을 담은 기술 메모, Mermaid 흐름도로 절차를 설명하는 인수인계 문서에 활용할 수 있습니다. 다운로드 가능한 예제에서 이 기능들을 한 보고서로 확인하세요.

    PDF는 어떻게 저장하나요?

    ‘인쇄 / PDF로 저장’을 누르고 브라우저나 시스템에서 PDF 저장 방식을 선택하세요. iPhone과 iPad에서는 시스템 인쇄 미리보기에서 PDF를 공유하거나 저장할 수 있습니다. 여기서는 보고서 내용을 미리 보여 주며, 추가 머리글과 용지 설정은 인쇄 대화상자에서 조절합니다.

    어떤 제한이 있나요?

    A4 레이아웃 한 종류, Markdown 최대 500 KB, 보고서 최대 100페이지입니다. 표의 행이 너무 높거나 요소를 안전하게 나눌 수 없으면 잘린 PDF 대신 안내를 표시합니다. 누락된 이미지와 유효하지 않은 다이어그램 또는 수식도 안내합니다. 첫 버전에서는 MDX 구성 요소, 사용자 지정 스크립트, TextBundle과 TextPack을 지원하지 않습니다.

    이 Markdown PDF 변환 도구는 무료인가요?

    네. 현재 웹 도구는 무료이며 계정이나 OnePreview 앱이 필요 없습니다. 문서 내용과 선택한 이미지는 현재 브라우저 세션에만 남고 변환 서버에 업로드되지 않습니다.

    Mermaid 다이어그램과 수식도 PDF로 내보낼 수 있나요?

    네. mermaid 코드 블록에 다이어그램을 작성하고 KaTeX 호환 문법으로 수식을 입력하세요. 인쇄 전에 미리보기를 확인하세요. 다이어그램이나 수식을 렌더링할 수 없으면 조용히 생략하지 않고 경고와 원문을 표시합니다.

    Markdown 표는 페이지를 넘어갈 때 어떻게 표시되나요?

    GitHub 스타일 Markdown 표는 A4 페이지로 나뉘며 각 페이지에 머리글 행을 반복합니다. 코드는 너비에 맞춰 줄바꿈합니다. 표의 한 행이 너무 높거나 내용이 페이지 너비를 넘으면 안내를 표시합니다. 행을 줄이거나 열 수를 줄인 뒤 다시 시도하세요.

    PDF에서 이미지가 보이지 않는 이유는 무엇인가요?

    Markdown이 참조하는 로컬 이미지를 파일 이름이 일치하도록 선택하세요. 원격 이미지는 자동으로 불러오지 않습니다. 최대 16개, 파일당 5 MB, 총 20 MB까지 선택할 수 있습니다. 누락되거나 읽을 수 없는 이미지는 경고로 표시합니다.

    로컬 파일 미리보기도 필요하신가요?

    Mac, iPhone, iPad용 OnePreview는 기기에서 Markdown과 개발자 파일을 미리 보여 줍니다. 이 웹 도구는 앱 없이도 독립적으로 사용할 수 있습니다.
