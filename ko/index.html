Markdown 미리보기

Mac Finder와 iPhone 및 iPad 파일 앱에서 읽기 좋은 Markdown을 확인하세요.

GitHub 스타일 렌더링

전체 편집기를 열지 않고 제목, 표, 작업 목록, 코드 블록, 알림, 문서형 Markdown을 미리 봅니다.

MDX, TextBundle, TextPack

일반적인 Markdown 패키지 형식을 폴더나 압축 파일이 아니라 읽기 좋은 문서로 엽니다.

Mermaid와 KaTeX 내장

내장 리소스로 다이어그램, 차트, 수식을 렌더링해 일반 Markdown 문서를 오프라인에서도 볼 수 있습니다.

렌더링 또는 원본

정확한 문법을 확인해야 할 때 HTML 미리보기와 원본 Markdown 소스를 전환합니다.

Markdown 그 이상

매일 확인하는 개발자 파일을 하나의 확장으로.

소스 코드

Swift, Python, JavaScript, TypeScript, C, C++, Objective-C, Rust, Go, Ruby, Java, Shell, Assembly 등.

구조화 데이터

JSON, JSONL, YAML, XML, CSV, TSV, TOML, ENV, Apple property list 등 텍스트 데이터 형식.

압축 파일과 폴더

ZIP/TAR.GZ 내용과 폴더 목록을 파일 크기, 수정일, 명확한 구조와 함께 탐색합니다.

SQLite 데이터베이스

데이터베이스 도구를 먼저 실행하지 않고 테이블, 뷰, 인덱스, 열, 샘플 행을 확인합니다.

기술 형식: Markdown, MDX, TextBundle, TextPack, JSON, JSONL, YAML, XML, CSV, TSV, TOML, ENV, SQLite, Swift, Python, JavaScript, TypeScript, C, C++, Objective-C, Rust, Go, Ruby, Java, Shell, Assembly, 소스 코드, 일반 텍스트, 로그, 폴더, ZIP/TAR.GZ 압축 파일, Apple 속성 목록(plist).

계정 불필요한 번 설치하고 파일을 기기에서 미리 보세요.
로컬 미리보기파일은 Apple 미리보기 메커니즘 안에서 처리됩니다.
무료 앱App Store로 제공됩니다.

워크플로

실제 Quick Look 습관에 맞게 설계.

Finder에 머물기

macOS에서 스페이스바를 눌러 전체 편집기 없이 지원 파일을 확인합니다.

iPhone과 iPad 지원

파일 앱에서 지원 파일을 길게 누르고 다음으로 열기를 선택한 뒤 OnePreview를 선택하세요. 일반 탭은 Apple 내장 미리보기를 사용할 수 있습니다.

설정 안내 포함

Mac에서는 Quick Look 확장 프로그램을 켜세요. iPhone과 iPad에서는 파일 앱의 다음으로 열기에서 OnePreview를 선택하세요.

설정 도움말 읽기

설정 및 파일 미리보기 가이드

Quick Look 확장 켜기

설치 후 OnePreview를 한 번 열고 시스템 확장 설정에서 활성화합니다.

개인정보와 파일 처리 이해

파일은 Apple 시스템 미리보기 메커니즘을 통해 로컬에서 미리 봅니다.

올바르게 표시되지 않는 파일 신고
