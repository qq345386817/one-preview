폴더 읽기와 검색

OnePreview에서 폴더를 열고 문서를 전환하거나 Markdown 상대 링크와 제목으로 이동하세요. 뒤로·앞으로 이동하며 읽던 곳을 찾고, 현재 세션 안에서는 읽기 모드와 위치를 복원합니다. 허용한 폴더의 파일 이름과 읽을 수 있는 텍스트를 검색하며, 스캔 한도에 도달하면 일부 결과임을 표시합니다. 검색 색인은 디스크에 저장하지 않습니다.

책갈피가 있는 PDF

앱에서 열린 폴더와 하위 폴더의 .md 또는 .markdown 문서를 최대 20개 선택하세요. 순서를 조정하고 미리 본 뒤 문서별 책갈피가 있는 A4 PDF로 내보냅니다. 최대 100페이지, 64 MiB까지 지원합니다. 접근 권한과 크기 제한 안에서 로컬 상대 경로 이미지를 포함하며, 누락·원격·폴더 밖 이미지는 자리 표시자로 알립니다. 원본 파일은 바뀌지 않습니다.

Markdown 읽기 설정

시스템 설정 따르기, 밝은색, 어두운색, 따뜻한 종이 테마와 글꼴, 글자 크기, 간격, 읽기 너비를 선택하세요.

Markdown 미리보기

Markdown을 읽기 편한 문서로.

GitHub 스타일 렌더링

전체 편집기를 열지 않고 제목, 표, 작업 목록, 코드 블록, 알림, 문서형 Markdown을 미리 봅니다.

MDX, TextBundle, TextPack

일반적인 Markdown 패키지 형식을 폴더나 압축 파일이 아니라 읽기 좋은 문서로 엽니다.

Mermaid와 KaTeX 내장

내장 리소스로 다이어그램, 차트, 수식을 렌더링해 일반 Markdown 문서를 오프라인에서도 볼 수 있습니다.

렌더링 또는 원본

정확한 문법을 확인해야 할 때 HTML 미리보기와 원본 Markdown 소스를 전환합니다.

Markdown 그 이상

문서 읽기, 데이터 확인, 압축 파일 내용 탐색.

소스 코드

Swift, Python, JavaScript, TypeScript, C, C++, Objective-C, Rust, Go, Ruby, Java, Shell, Assembly 등.

구조화 데이터

JSON, JSONL/NDJSON, YAML, XML, CSV, TSV, TOML, ENV, INI, properties, Apple property list 등 텍스트 데이터 형식.

압축 파일과 폴더

ZIP/TAR.GZ/TGZ 내용과 폴더 목록을 파일 크기, 수정일, 명확한 구조와 함께 탐색합니다.

SQLite 데이터베이스

데이터베이스 도구를 먼저 실행하지 않고 테이블, 뷰, 인덱스, 열, 샘플 행을 확인합니다.

기술 형식: Markdown, MDX, TextBundle, TextPack, JSON, JSONL/NDJSON, YAML, XML, CSV, TSV, TOML, ENV, INI, properties, SQLite, Swift, Python, JavaScript, TypeScript, C, C++, Objective-C, Rust, Go, Ruby, Java, Shell, Assembly, 소스 코드, 일반 텍스트, 로그, 폴더, ZIP/TAR.GZ/TGZ 압축 파일, Apple 속성 목록(plist).

OnePreview App · Markdown → PDF

앱에서 Markdown을 가져와 PDF 보고서로 저장

Mac, iPhone, iPad의 OnePreview에서 파일 > 도구 > Markdown을 PDF로 변환 이동해 .md 또는 .markdown 파일을 가져오세요. 실제 A4 PDF를 확인한 뒤 저장할 수 있습니다. 표, 코드 줄바꿈, Mermaid 다이어그램, KaTeX 수식을 지원합니다. PDF 내보내기는 기본 앱에서 제공하며 Finder Quick Look에서는 제공하지 않습니다. OnePreview는 편집기가 아닌 뷰어입니다.

브라우저에서 무료로 Markdown PDF 변환

프로젝트 주간 보고서, 기술 문서와 인수인계 자료를 A4 PDF로 만드세요. 웹 변환 도구는 OnePreview 앱 없이도 독립적으로 사용할 수 있습니다.

설치나 문서 업로드 불필요

.md, .markdown 파일을 열거나 내용을 붙여 넣으세요. 문서와 선택한 이미지는 현재 브라우저 세션에서 처리되며 계정이나 앱이 필요 없습니다.

표, Mermaid 다이어그램과 수식 유지

A4 페이지 나누기, 반복되는 표 머리글, 줄바꿈된 코드, Mermaid와 KaTeX 수식을 확인한 뒤 ‘인쇄 / PDF로 저장’으로 내보내세요.
