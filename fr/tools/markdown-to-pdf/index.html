Du Markdown au PDF, prêt à partager.

Une mise en page A4 claire, avec numéros de page, en-têtes de tableau répétés et code lisible. Vérifiez chaque page, puis enregistrez le rapport en PDF.

Pour ![Graphique](images/chart.png), choisissez aussi chart.png. Les images distantes ne sont pas chargées. Jusqu’à 16 images de 5 Mo chacune.

Aperçu du rapportA4 · 210 × 297 mm

Préparation de l’exemple…

    Choisissez A4 et une échelle de 100 %. Désactivez les en-têtes et pieds de page du navigateur ; le rapport contient ses propres numéros de page.

    Votre document et les images choisies restent dans cette session du navigateur. Rien n’est envoyé ni enregistré sur ce site.

    Un rapport à lire et à copier

    Le PDF contient du texte, pas des captures du document. Le Markdown standard, les tableaux GitHub, les blocs de code, les diagrammes Mermaid et les formules KaTeX sont pris en charge. Les tableaux longs répètent leurs en-têtes sur chaque page ; le code long revient à la ligne selon la largeur disponible.

    Télécharger l’exemple Markdown pour essayer le même rapport dans un autre outil.

    Comment enregistrer le PDF ?

    Utilisez « Imprimer / Enregistrer en PDF », puis choisissez la destination PDF dans le navigateur ou le système. Sur iPhone et iPad, partagez ou enregistrez le PDF depuis l’aperçu d’impression du système. L’aperçu montre le rapport ; les en-têtes ajoutés et le format du papier se règlent dans la fenêtre d’impression.

    Quelles sont les limites ?

    Une mise en page A4, jusqu’à 500 Ko de Markdown et 100 pages. Une ligne de tableau trop haute ou un élément impossible à diviser proprement déclenche un message au lieu d’un PDF tronqué. Les images manquantes et les diagrammes ou formules invalides sont signalés. Cette première version exclut les composants MDX, les scripts personnalisés, TextBundle et TextPack.

    Besoin d’aperçus de fichiers locaux ?

    OnePreview pour Mac, iPhone et iPad affiche le Markdown et les fichiers de développement sur votre appareil. Cet outil web fonctionne indépendamment de l’application.
