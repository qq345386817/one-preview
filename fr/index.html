Extension Quick Look pour macOS, iOS et iPadOS

Prévisualisez Markdown avec Quick Look, puis continuez avec vos fichiers développeur.

OnePreview affiche le Markdown de style GitHub avec coloration syntaxique, diagrammes Mermaid et formules KaTeX dans le flux de prévisualisation système. Il affiche aussi le code, les données structurées, ZIP, dossiers et SQLite avant d’ouvrir un éditeur.

Aperçu Markdown

Markdown lisible depuis Finder, Fichiers et Quick Look.

Rendu façon GitHub

Aperçu des titres, tableaux, listes de tâches, blocs de code, alertes et Markdown de documentation sans ouvrir un éditeur complet.

MDX, TextBundle, TextPack

Ouvrez les formats de paquets Markdown courants comme des documents lisibles plutôt que comme dossiers ou archives.

Mermaid et KaTeX intégrés

Affichez diagrammes, graphiques et formules avec des ressources incluses, même hors ligne pour les documents courants.

Rendu ou source

Passez de l’aperçu HTML lisible au Markdown original quand vous devez inspecter la syntaxe exacte.

Au-delà de Markdown

Une extension pour les fichiers développeur que vous inspectez chaque jour.

Code source

Swift, Python, JavaScript, TypeScript, C, C++, Objective-C, Rust, Go, Ruby, Java, scripts shell, Assembly, et plus.

Données structurées

JSON, JSONL, YAML, XML, CSV, TSV, TOML, ENV, property lists Apple et autres formats texte.

Archives et dossiers

Parcourez le contenu ZIP et les dossiers avec tailles, dates de modification et structure claire.

Bases SQLite

Inspectez tables, vues, index, colonnes et lignes d’exemple sans lancer d’outil de base de données.

Formats techniques : Markdown, MDX, TextBundle, TextPack, JSON, JSONL, YAML, XML, CSV, TSV, TOML, ENV, SQLite, Swift, Python, JavaScript, TypeScript, C, C++, Objective-C, Rust, Go, Ruby, Java, Shell, Assembly, source code, plain text, logs, folders, ZIP archives, Apple property lists (plist).

Flux de travail

Pensé pour les habitudes réelles de Quick Look.

Rester dans Finder

Appuyez sur la barre d’espace sur macOS pour inspecter les fichiers pris en charge sans lancer un éditeur complet.

Fonctionne sur iPhone et iPad

Utilisez l’app Fichiers ou toute app ouvrant les aperçus Quick Look système.

Guide inclus

Ouvrez OnePreview une fois, activez l’extension et gardez les étapes de dépannage à portée de main.

Lire l’aide de configuration

Guides de configuration et de prévisualisation

Activer l’extension Quick Look

Ouvrez OnePreview une fois après l’installation, puis activez-la dans les réglages d’extensions système.

Comprendre la confidentialité et le traitement

Les fichiers sont prévisualisés localement via les mécanismes système Apple.

Signaler un fichier mal affiché

Envoyez le type de fichier, la version du système et une courte note de reproduction.
