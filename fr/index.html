OnePreview App · Markdown → PDF

Importer un Markdown dans l’app et exporter un rapport PDF

Dans OnePreview sur Mac, iPhone ou iPad, ouvrez Fichiers > Outils > Markdown vers PDF et importez un fichier .md ou .markdown. Vérifiez le PDF A4 réel avant de l’enregistrer. Les tableaux, le retour à la ligne du code, Mermaid et KaTeX sont pris en charge. L’export PDF se fait dans l’app principale, pas dans Quick Look du Finder. OnePreview est un lecteur, pas un éditeur.

Flux de travail

Pensé pour les habitudes réelles de Quick Look.

Rester dans Finder

Appuyez sur la barre d’espace sur macOS pour inspecter les fichiers pris en charge sans lancer un éditeur complet.

Fonctionne sur iPhone et iPad

Dans Fichiers, maintenez un fichier compatible, choisissez « Ouvrir avec », puis OnePreview. Un toucher simple peut utiliser l’aperçu intégré d’Apple.

Guide inclus

Activez l’extension Quick Look sur Mac. Sur iPhone et iPad, utilisez Ouvrir avec > OnePreview depuis Fichiers.

Choisissez votre éditeur sur Mac

Ouvrez le fichier original dans votre éditeur depuis OnePreview ou Quick Look dans le Finder. Mémorisez un choix par type de fichier sans modifier les réglages par défaut de macOS.

Guides de configuration et de prévisualisation

Activer l’extension Quick Look

Ouvrez OnePreview une fois après l’installation, puis activez-la dans les réglages d’extensions système.

Comprendre la confidentialité et le traitement

Les fichiers sont prévisualisés localement via les mécanismes système Apple.

Signaler un fichier mal affiché

Envoyez le type de fichier, la version du système et une courte note de reproduction.
