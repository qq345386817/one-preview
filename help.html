OnePreview Help

Enable Finder Quick Look on Mac, or use Open With from Files on iPhone and iPad.

Download on the App Store

How do I enable OnePreview on macOS?

Open OnePreview once after installation. On macOS Sequoia, go to System Settings > General > Login Items & Extensions > Quick Look and enable OnePreview. On macOS Sonoma, use System Settings > Privacy & Security > Extensions > Quick Look.

How do I use OnePreview on iPhone or iPad?

In Files, long-press a supported file, choose Open With, then select OnePreview. A normal tap may use Apple’s built-in preview.

Which file formats are supported?

Markdown, MDX, TextBundle, TextPack, JSON, JSONL, YAML, XML, CSV, TSV, TOML, ENV, SQLite databases, source code, plain text, logs, folders, ZIP/TAR.GZ archives, and Apple property lists.

Why does a Markdown preview sometimes show an older version?

macOS Quick Look can cache preview snapshots. Close the preview, reopen it with Spacebar, and run qlmanage -r && qlmanage -r cache if Finder keeps showing stale content during development.

Why do some local Markdown images not appear?

Apple sandbox rules limit what a Quick Look extension can read next to the selected file. Web image URLs are the most reliable option.

Does OnePreview edit files?

No. OnePreview is a viewer and does not modify your documents.

OnePreview adds Finder Quick Look previews on macOS and local file viewing on iPhone and iPad.
