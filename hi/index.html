OnePreview

macOS, iOS और iPadOS Quick Look extension

Markdown files को Quick Look करें, फिर बाकी developer files भी देखें।

OnePreview system preview flow में GitHub-style Markdown render करता है, syntax highlighting, Mermaid diagrams और KaTeX math के साथ। Editor खोलने से पहले code, structured data, ZIP, folders और SQLite भी inspect करें।

Markdown प्रीव्यू

Finder, Files और Quick Look से readable Markdown।

GitHub-style rendering

Headings, tables, task lists, fenced code blocks, alerts और documentation-style Markdown को full editor खोले बिना preview करें।

MDX, TextBundle, TextPack

Common Markdown package formats को plain folders या archives की जगह readable documents की तरह खोलें।

Mermaid और KaTeX built in

Bundled assets से diagrams, charts और math formulas render करें, ताकि common Markdown documents offline भी काम करें।

Rendered या raw

Exact syntax inspect करने के लिए readable HTML preview और original Markdown source के बीच switch करें।

Markdown से आगे

हर दिन inspect की जाने वाली developer files के लिए एक extension।

Source code

Swift, Python, JavaScript, TypeScript, C, C++, Objective-C, Rust, Go, Ruby, Java, shell scripts, Assembly और अधिक।

Structured data

JSON, JSONL, YAML, XML, CSV, TSV, TOML, ENV, Apple property lists और दूसरे text-based data formats।

Archives और folders

ZIP archive contents और folder listings को file sizes, modification dates और साफ structure के साथ browse करें।

SQLite databases

Database tool चलाए बिना tables, views, indexes, columns और sample rows inspect करें।

Workflow

असली Quick Look habits के लिए design किया गया।

Finder में रहें

macOS पर Spacebar दबाकर supported files देखें, full editor खोलने की जरूरत नहीं।

iPhone और iPad पर भी

Files app या system Quick Look खोलने वाली किसी भी app में इस्तेमाल करें।

Setup guidance शामिल
