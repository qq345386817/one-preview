Markdown प्रीव्यू

Mac पर Finder में और iPhone या iPad पर Files से साफ़ Markdown preview।

GitHub शैली का रेंडरिंग

पूरा एडिटर खोले बिना शीर्षक, तालिकाएँ, कार्य सूचियाँ, फ़ेंस्ड कोड ब्लॉक, अलर्ट और दस्तावेज़ शैली का Markdown देखें।

MDX, TextBundle, TextPack

सामान्य Markdown पैकेज फ़ॉर्मेट को साधारण फ़ोल्डर या आर्काइव की जगह पढ़ने योग्य दस्तावेज़ की तरह खोलें।

Mermaid और KaTeX साथ में

साथ दिए संसाधनों से डायग्राम, चार्ट और गणितीय सूत्र रेंडर करें, ताकि सामान्य Markdown दस्तावेज़ ऑफ़लाइन भी काम करें।

रेंडर किया हुआ या सोर्स

सटीक सिंटैक्स जाँचने के लिए पढ़ने योग्य HTML प्रीव्यू और मूल Markdown सोर्स के बीच बदलें।

Markdown से आगे

रोज़ जाँची जाने वाली डेवलपर फ़ाइलों के लिए एक एक्सटेंशन।

सोर्स कोड

Swift, Python, JavaScript, TypeScript, C, C++, Objective-C, Rust, Go, Ruby, Java, Shell स्क्रिप्ट, Assembly और अन्य।

संरचित डेटा

JSON, JSONL, YAML, XML, CSV, TSV, TOML, ENV, Apple प्रॉपर्टी लिस्ट और अन्य टेक्स्ट-आधारित डेटा फ़ॉर्मेट।

आर्काइव और फ़ोल्डर

ZIP/TAR.GZ की सामग्री और फ़ोल्डर सूची को फ़ाइल आकार, बदलाव की तारीख और साफ़ संरचना के साथ देखें।

SQLite डेटाबेस

डेटाबेस टूल खोले बिना तालिकाएँ, व्यू, इंडेक्स, कॉलम और नमूना पंक्तियाँ जाँचें।

तकनीकी फ़ॉर्मेट: Markdown, MDX, TextBundle, TextPack, JSON, JSONL, YAML, XML, CSV, TSV, TOML, ENV, SQLite, Swift, Python, JavaScript, TypeScript, C, C++, Objective-C, Rust, Go, Ruby, Java, Shell, Assembly, सोर्स कोड, सादा टेक्स्ट, लॉग, फ़ोल्डर, ZIP/TAR.GZ आर्काइव और Apple प्रॉपर्टी लिस्ट (plist)।

खाते की जरूरत नहींएक बार install करें और files को local preview करें।
स्थानीय प्रीव्यूफ़ाइलें Apple के प्रीव्यू तंत्र के भीतर ही रहती हैं।
मुफ़्त ऐपApp Store पर उपलब्ध।

कार्यप्रवाह

वास्तविक Quick Look उपयोग के लिए बनाया गया।

Finder में रहें

macOS पर Spacebar दबाकर समर्थित फ़ाइलें देखें; पूरा एडिटर खोलने की जरूरत नहीं।

iPhone और iPad पर भी

Files में supported file को दबाकर रखें, Open With चुनें, फिर OnePreview चुनें। सामान्य tap पर Apple का built-in preview खुल सकता है।

सेटअप मार्गदर्शन शामिल

Mac पर Quick Look extension चालू करें। iPhone और iPad पर Files से Open With > OnePreview इस्तेमाल करें।

सेटअप सहायता पढ़ें

सेटअप और फ़ाइल प्रीव्यू मार्गदर्शिका

Quick Look एक्सटेंशन सक्षम करें

इंस्टॉल करने के बाद OnePreview एक बार खोलें, फिर सिस्टम एक्सटेंशन सेटिंग में इसे सक्षम करें।

गोपनीयता और फ़ाइल प्रबंधन समझें

फ़ाइलों का प्रीव्यू Apple के सिस्टम तंत्र से डिवाइस पर ही बनता है।

गलत प्रीव्यू वाली फ़ाइल की रिपोर्ट करें

फ़ाइल प्रकार, OS संस्करण और समस्या दोहराने के छोटे चरण भेजें।
