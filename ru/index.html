Предпросмотр Markdown

Читаемый Markdown в Finder на Mac и из «Файлов» на iPhone и iPad.

Рендеринг в стиле GitHub

Просматривайте заголовки, таблицы, списки задач, блоки кода, уведомления и документационный Markdown без полноценного редактора.

MDX, TextBundle, TextPack

Открывайте распространенные Markdown-пакеты как читаемые документы, а не как обычные папки или архивы.

Встроенные Mermaid и KaTeX

Отображайте диаграммы, графики и формулы с помощью встроенных ресурсов, чтобы типичные Markdown-документы работали офлайн.

Рендеринг или исходник

Переключайтесь между читаемым HTML-предпросмотром и исходным Markdown, когда нужно проверить точный синтаксис.

Не только Markdown

Одно расширение для файлов разработчика, которые вы проверяете каждый день.

Исходный код

Swift, Python, JavaScript, TypeScript, C, C++, Objective-C, Rust, Go, Ruby, Java, Shell, Assembly и другое.

Структурированные данные

JSON, JSONL, YAML, XML, CSV, TSV, TOML, ENV, Apple property lists и другие текстовые форматы данных.

Архивы и папки

Просматривайте содержимое ZIP/TAR.GZ и списки папок с размерами файлов, датами изменений и понятной структурой.

Базы SQLite

Проверяйте таблицы, представления, индексы, столбцы и примеры строк без запуска инструмента БД.

Технические форматы: Markdown, MDX, TextBundle, TextPack, JSON, JSONL, YAML, XML, CSV, TSV, TOML, ENV, SQLite, Swift, Python, JavaScript, TypeScript, C, C++, Objective-C, Rust, Go, Ruby, Java, Shell, Assembly, исходный код, обычный текст, журналы, папки, ZIP/TAR.GZ-архивы и списки свойств Apple (plist).

Рабочий процесс

Создано для реальных привычек Quick Look.

Оставайтесь в Finder

Нажмите пробел в macOS, чтобы проверить поддерживаемые файлы без запуска редактора.

Работает на iPhone и iPad

В «Файлах» удерживайте поддерживаемый файл, выберите «Открыть в приложении», затем OnePreview. Обычное касание может открыть встроенный просмотр Apple.

Есть руководство по настройке

Включите расширение Quick Look на Mac. На iPhone и iPad используйте «Открыть в» > OnePreview в приложении «Файлы».

Открыть справку по настройке

Руководства по настройке и предпросмотру

Включите расширение Quick Look

После установки откройте OnePreview один раз, затем включите его в настройках расширений системы.

Понимание конфиденциальности и обработки файлов

Файлы просматриваются локально через системные механизмы Apple.

Сообщить о файле с неправильным просмотром

Отправьте тип файла, версию ОС и короткое описание воспроизведения.

Markdown → PDF

Бесплатная конвертация Markdown в PDF в браузере

Создавайте PDF A4 из отчётов по проекту, технической документации и заметок для передачи дел. Веб-инструмент работает независимо от приложения OnePreview.

Без установки и загрузки документов на сервер

Откройте файл .md или .markdown либо вставьте текст. Документ и выбранные изображения обрабатываются в текущем сеансе браузера, без аккаунта и приложения.

Таблицы, диаграммы Mermaid и формулы

Проверьте страницы A4, повторяющиеся заголовки таблиц, переносы кода, диаграммы Mermaid и формулы KaTeX перед печатью или сохранением PDF.
