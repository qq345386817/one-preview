Рабочий процесс

Создано для реальных привычек Quick Look.

Оставайтесь в Finder

Нажмите пробел в macOS, чтобы проверить поддерживаемые файлы без запуска редактора.

Работает на iPhone и iPad

В «Файлах» удерживайте поддерживаемый файл, выберите «Открыть в приложении», затем OnePreview. Обычное касание может открыть встроенный просмотр Apple.

Есть руководство по настройке

Включите расширение Quick Look на Mac. На iPhone и iPad используйте «Открыть в» > OnePreview в приложении «Файлы».

Выберите редактор на Mac

Открывайте исходный файл в любимом редакторе из OnePreview или Quick Look в Finder. Запоминайте выбор для расширения, не меняя приложения macOS по умолчанию.
