Bantuan OnePreview

Aktifkan Finder Quick Look di Mac, atau gunakan Open With dari Files di iPhone dan iPad.

Unduh di App Store Baca bantuan setup

Bagaimana cara mengaktifkan OnePreview di macOS?

Buka OnePreview sekali setelah instalasi. Di macOS Sequoia, buka System Settings > General > Login Items & Extensions > Quick Look lalu aktifkan OnePreview. Di macOS Sonoma, gunakan System Settings > Privacy & Security > Extensions > Quick Look.

Bagaimana menggunakan OnePreview di iPhone atau iPad?

Di Files, tekan lama file yang didukung, pilih Open With, lalu OnePreview. Ketukan biasa dapat memakai pratinjau bawaan Apple.

Format file apa yang didukung?

Markdown, MDX, TextBundle, TextPack, JSON, JSONL, YAML, XML, CSV, TSV, TOML, ENV, database SQLite, kode sumber, teks biasa, log, folder, arsip ZIP/TAR.GZ, dan Apple property list.

Mengapa pratinjau Markdown kadang menampilkan versi lama?

macOS Quick Look dapat menyimpan snapshot pratinjau. Tutup pratinjau, buka lagi dengan Spacebar, dan jalankan qlmanage -r && qlmanage -r cache jika Finder masih menampilkan konten lama saat pengembangan.

Mengapa beberapa gambar Markdown lokal tidak muncul?

Aturan sandbox Apple membatasi file lain di sekitar file terpilih yang dapat dibaca ekstensi Quick Look. URL gambar web adalah opsi paling andal.

Apakah OnePreview mengedit file?

Tidak. OnePreview adalah viewer dan tidak mengubah dokumen Anda.

OnePreview menambahkan Finder Quick Look di macOS dan penampil file lokal di iPhone dan iPad.
