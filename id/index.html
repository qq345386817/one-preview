Baca, cari, dan ekspor folder Markdown

Baca dan cari dalam folder

Buka folder di OnePreview, pindah berkas, dan ikuti tautan relatif serta judul Markdown. Mundur dan Maju menelusuri riwayat baca; mode dan posisi diingat selama sesi. Cari nama berkas dan teks yang dapat dibaca dalam folder yang diizinkan. Batas pemindaian dapat menghasilkan sebagian hasil; indeks pencarian tidak disimpan ke disk.

Satu PDF dengan penanda

Di aplikasi, pilih hingga 20 berkas .md atau .markdown dari folder terbuka dan subfoldernya. Atur urutan, periksa pratinjau, lalu ekspor satu PDF A4 dengan penanda untuk tiap dokumen. Batasnya 100 halaman dan 64 MiB. Gambar lokal dengan jalur relatif disertakan sesuai batas izin dan ukuran; gambar hilang, jarak jauh, atau di luar folder memakai penanda pengganti. Berkas asli tidak berubah.

OnePreview App · Markdown → PDF

Impor Markdown dalam app dan ekspor laporan PDF

Di OnePreview pada Mac, iPhone atau iPad, buka File > Alat > Markdown ke PDF lalu impor file .md atau .markdown. Periksa PDF A4 yang sebenarnya sebelum menyimpannya. Mendukung tabel, pelipatan baris kode, diagram Mermaid dan rumus KaTeX. Ekspor PDF tersedia dalam app utama, bukan Finder Quick Look. OnePreview adalah pembaca, bukan editor.
