Pratinjau Markdown

Markdown yang mudah dibaca di Finder pada Mac dan dari Files pada iPhone atau iPad.

Rendering gaya GitHub

Pratinjau heading, tabel, task list, blok kode, alert, dan Markdown dokumentasi tanpa membuka editor penuh.

MDX, TextBundle, TextPack

Buka format paket Markdown umum sebagai dokumen yang mudah dibaca, bukan sebagai folder atau arsip biasa.

Mermaid dan KaTeX bawaan

Render diagram, bagan, dan rumus matematika dengan aset bawaan sehingga dokumen Markdown umum tetap berjalan offline.

Rendered atau raw

Beralih antara pratinjau HTML yang mudah dibaca dan sumber Markdown asli saat perlu memeriksa sintaks persis.

Di luar Markdown

Satu ekstensi untuk file developer yang Anda periksa setiap hari.

Kode sumber

Swift, Python, JavaScript, TypeScript, C, C++, Objective-C, Rust, Go, Ruby, Java, skrip shell, Assembly, dan lainnya.

Data terstruktur

JSON, JSONL, YAML, XML, CSV, TSV, TOML, ENV, Apple property list, dan format data berbasis teks lainnya.

Arsip dan folder

Jelajahi isi ZIP/TAR.GZ dan daftar folder dengan ukuran file, tanggal modifikasi, dan struktur yang jelas.

Database SQLite

Periksa tabel, view, indeks, kolom, dan baris contoh tanpa menjalankan tool database terlebih dahulu.
