Preparing the example…

    Choose A4 and 100% scale. Turn off browser headers and footers; the report includes its own page numbers.

    Your document and chosen images stay in this browser session. Nothing is uploaded or saved to this website.

    A report you can read and copy

    The PDF uses text, not screenshots of the document. Standard Markdown, GitHub-style tables, code blocks, Mermaid diagrams and KaTeX math are supported. Long tables continue with their headers on each page; long code wraps to the available width.

    Download the example Markdown to try the same report in another workflow.

    How do I save the PDF?

    Use Print / Save as PDF, then choose your browser or system PDF destination. On iPhone and iPad, use the system print preview to share or save the PDF. The preview shows the report content; browser-added print headers and paper settings are controlled by the print dialog.

    What are the limits?

    One A4 layout, up to 500 KB of Markdown and 100 pages. Oversized table rows or elements that cannot be split safely produce a message instead of a clipped PDF. Missing images and invalid diagrams or formulas are reported. MDX components, custom scripts, TextBundle and TextPack are outside this tool's first release.

    Looking for local file previews?

    OnePreview for Mac, iPhone and iPad previews Markdown and developer files on your device. This web tool works independently of the app.
