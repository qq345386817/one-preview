من Markdown إلى PDF، جاهز للمشاركة.

امنح تقريرك تنسيق A4 واضحًا، مع أرقام صفحات ورؤوس جداول متكررة وشيفرة مقروءة. عاين كل صفحة ثم احفظ التقرير بصيغة PDF.

اختر ملف .md أو .markdown بحد أقصى 500 كيلوبايت، بترميز UTF-8 أو UTF-16. يجب اختيار الصور المشار إليها بشكل منفصل.

عند استخدام ![Chart](images/chart.png)، اختر أيضًا chart.png. لا تُجلب الصور البعيدة. حتى 16 صورة، بحد أقصى 5 ميغابايت لكل صورة.

جارٍ تجهيز المثال…

    اختر A4 ومقياس 100%. أوقف رؤوس المتصفّح وتذييلاته؛ يتضمن التقرير أرقام صفحاته.

    يبقى المستند والصور التي تختارها في جلسة المتصفّح الحالية. لا تُرفع إلى هذا الموقع ولا تُحفظ فيه.

    تقرير واضح بنص قابل للتحديد

    يستخدم PDF نصًا حقيقيًا وليس صورًا للمستند. يدعم Markdown القياسي وجداول GitHub وكتل الشيفرة ومخططات Mermaid ومعادلات KaTeX. تستمر الجداول الطويلة مع تكرار رؤوسها في كل صفحة، وتلتف الشيفرة الطويلة ضمن العرض المتاح.

    تستخدم هذه الأداة طباعة المتصفح. قد يُنسخ بعض النص العربي برموز Unicode لأشكال الحروف بدلاً من رموز الأحرف الأصلية، حسب المتصفح وقارئ PDF. تحقّق من النص المنسوخ إذا كانت مطابقة الأحرف الأصلية ضرورية. يستخدم تصدير PDF داخل تطبيق OnePreview معالجة منفصلة لتصحيح تعيين الأحرف.

    تنزيل مثال Markdown لتجربة التقرير نفسه في طريقة عمل أخرى.

    تقارير ومستندات وملاحظات تسليم

    استخدم أداة تحويل Markdown إلى PDF لتقرير أسبوعي مع جدول تقدّم، أو ملاحظات تقنية مع شيفرة ومعادلات، أو مستند تسليم مع مخطط Mermaid. يجمع المثال القابل للتنزيل هذه المزايا في تقرير واحد.

    كيف أحفظ PDF؟

    اختر «طباعة / حفظ PDF»، ثم وجهة PDF في المتصفّح أو النظام. على iPhone وiPad، استخدم معاينة الطباعة في النظام لمشاركة الملف أو حفظه. تعرض المعاينة محتوى التقرير، أما الرؤوس التي يضيفها المتصفّح وإعدادات الورق فتحدّدها نافذة الطباعة.

    ما حدود الأداة؟

    تنسيق A4 واحد، وحتى 500 كيلوبايت من Markdown و100 صفحة. تظهر رسالة إذا كان صف جدول أكبر من صفحة أو تعذّر تقسيم عنصر بأمان، بدلًا من إنتاج PDF مقصوص. يُبلّغ عن الصور المفقودة والمخططات أو المعادلات غير الصالحة. مكوّنات MDX والبرامج النصية المخصّصة وTextBundle وTextPack غير مدعومة في الإصدار الأول من الأداة.

    هل أداة تحويل Markdown إلى PDF مجانية؟

    نعم. أداة الويب الحالية مجانية وتعمل دون حساب أو تطبيق OnePreview. يبقى نص المستند والصور المحدّدة في جلسة المتصفّح الحالية، ولا تُرفع إلى خادم تحويل.

    هل يمكنني تصدير مخططات Mermaid والمعادلات إلى PDF؟

    نعم. ضع المخطط في كتلة شيفرة مسيّجة من نوع mermaid واستخدم صياغة معادلات متوافقة مع KaTeX. راجع المعاينة قبل الطباعة. إذا تعذّر عرض مخطط أو معادلة، تظهر رسالة تنبيه ويُحتفظ بالنص الأصلي بدلًا من حذفه دون إشعار.

    كيف تستمر جداول Markdown عبر الصفحات؟

    تُقسّم جداول Markdown بأسلوب GitHub على صفحات A4 مع تكرار صف الرأس. تلتف الشيفرة ضمن العرض المتاح. إذا تجاوز صف ارتفاع الصفحة أو ظل المحتوى أعرض منها، تُبلغ الأداة بالمشكلة؛ اختصر الصف أو قلّل الأعمدة ثم حاول مجددًا.

    لماذا لا تظهر الصور في ملف PDF؟

    اختر ملفات الصور المحلية المشار إليها في Markdown بأسماء مطابقة. لا تُجلب الصور البعيدة تلقائيًا. يمكنك اختيار حتى 16 صورة، بحد أقصى 5 ميغابايت للصورة و20 ميغابايت إجمالًا؛ تظهر رسالة عند فقدان صورة أو تعذّر قراءتها.

    هل تبحث عن معاينة محلية للملفات؟

    يعاين OnePreview على Mac وiPhone وiPad ملفات Markdown وملفات المطوّرين على جهازك. تعمل أداة الويب هذه بشكل مستقل عن التطبيق.
