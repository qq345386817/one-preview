OnePreview 帮助

在 Mac 上启用 Finder 快速查看；在 iPhone 与 iPad 上使用“文件”App 的“打开方式”。

在 App Store 下载

如何在 macOS 启用 OnePreview？

安装后先打开一次 OnePreview。macOS Sequoia 前往 系统设置 > 通用 > 登录项与扩展 > 快速查看 启用 OnePreview；macOS Sonoma 前往 系统设置 > 隐私与安全性 > 扩展 > 快速查看。

如何在 iPhone 或 iPad 使用？

在“文件”App 中长按支持的文件，选择“打开方式”，再选择 OnePreview。普通点击可能会使用 Apple 内置预览。

支持哪些文件格式？

Markdown、MDX、TextBundle、TextPack、JSON、JSONL/NDJSON、YAML、XML、CSV、TSV、TOML、ENV, INI, properties、SQLite 数据库、源码、纯文本、日志、文件夹、ZIP/TAR.GZ/TGZ 压缩包和 Apple plist。

为什么 Markdown 预览有时没有立即更新？

macOS Quick Look 可能缓存预览快照。可以先关闭预览，再按空格重新打开；开发调试时如果 Finder 仍显示旧内容，可运行 qlmanage -r && qlmanage -r cache 重置缓存。

为什么部分 Markdown 本地图片不显示？

Apple 沙盒规则会限制 Quick Look 扩展读取所选文件旁边的本地资源。网络图片链接通常最稳定。

OnePreview 会编辑文件吗？

不会。OnePreview 是查看器，不会修改你的文档。

App 内能导入 Markdown 并导出 PDF 吗？

在 Mac、iPhone 或 iPad 的 OnePreview 中，前往“文件 > 工具 > Markdown 转 PDF”，导入 .md 或 .markdown 文件。检查实际 A4 PDF 后再保存，支持表格、代码换行、Mermaid 流程图和 KaTeX 公式。PDF 导出属于主 App，不在 Finder 快速查看中提供。OnePreview 是查看器，不是编辑器。

如何在 Mac 上为文件类型选择编辑器？

在 macOS 版 OnePreview 中打开文件，通过“打开方式”选择已安装的应用，可按文件扩展名记住选择，并在“设置”>“外部打开方式”中更改或移除。Finder 快速查看会读取主 App 保存的选择，也可以从预览中的“打开方式”菜单临时选择应用。打开的是原始文件，不会更改 macOS 默认文件关联。此编辑器偏好功能仅适用于 macOS，与 iPhone/iPad 在“文件”App 中选择 OnePreview 是不同的操作。

OnePreview 为 macOS 提供 Finder 快速查看扩展，并为 iPhone 与 iPad 提供本地文件查看功能。
