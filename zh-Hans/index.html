macOS Finder 快速查看 · iPhone 与 iPad 文件查看器

打开编辑器前，先看懂 Markdown。

OnePreview 在系统预览流程里渲染 GitHub 风格 Markdown，支持语法高亮、Mermaid 图表和 KaTeX 数学公式。它还可以在打开编辑器前预览源码、结构化数据、ZIP/TAR.GZ 压缩包、文件夹和 SQLite 数据库。

Markdown Preview

在 Mac Finder 中快速查看，或从 iPhone 与 iPad 的“文件”App 打开清晰的 Markdown。

GitHub 风格渲染

无需打开完整编辑器，即可预览标题、表格、任务列表、围栏代码块、提示块和文档型 Markdown。

MDX、TextBundle、TextPack

把常见 Markdown 包格式作为可读文档打开，而不是只看到文件夹或压缩包列表。

内置 Mermaid 与 KaTeX

使用随 App 打包的资源渲染图表、流程图和数学公式，常见 Markdown 文档可离线工作。

渲染与源码切换

需要检查原始语法时，可在可读 HTML 预览和 Markdown 源码之间切换。

不止 Markdown

覆盖日常检查的开发者文件。

源码文件

Swift、Python、JavaScript、TypeScript、C、C++、Objective-C、Rust、Go、Ruby、Java、Shell、Assembly 等。

结构化数据

JSON、JSONL、YAML、XML、CSV、TSV、TOML、ENV、Apple plist 等文本数据格式。

压缩包与文件夹

浏览 ZIP/TAR.GZ 压缩包内容和文件夹列表，查看文件大小、修改时间与层级结构。

SQLite 数据库

在打开数据库工具前，先检查表、视图、索引、字段和少量样本行。

技术格式： Markdown、MDX、TextBundle、TextPack、JSON、JSONL、YAML、XML、CSV、TSV、TOML、ENV、SQLite、Swift、Python、JavaScript、TypeScript、C、C++、Objective-C、Rust、Go、Ruby、Java、Shell、Assembly、源码、纯文本、日志、文件夹、ZIP/TAR.GZ 压缩包、Apple 属性列表（plist）。

无需账户安装一次，即可在本地查看文件。
本机预览文件留在 Apple 系统预览机制内处理。
免费使用提供 App Store 版本。

工作流

为真实 Quick Look 使用习惯设计。

留在 Finder

macOS 中按空格键即可检查受支持文件，不必打开完整编辑器。

支持 iPhone 和 iPad

在“文件”App 中长按支持的文件，选择“打开方式”，再选择 OnePreview。普通点击可能会使用 Apple 内置预览。

内置启用指引

在 Mac 上启用快速查看扩展；在 iPhone 与 iPad 上从“文件”App 使用“打开方式”> OnePreview。
