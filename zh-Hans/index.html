OnePreview 1.5.1 功能

连续阅读、搜索和导出 Markdown 文件夹

文件夹连续阅读与搜索

在 OnePreview 中打开文件夹，切换文档、跟随 Markdown 相对链接与标题跳转，并通过前进、后退回到阅读位置。阅读模式和位置在当前会话内保留。可搜索授权目录内的文件名与可读文本；达到扫描上限时会提示部分结果，不在磁盘保存搜索索引。

合并为带书签的 PDF

在主 App 中，从已打开的文件夹及子目录选择最多 20 份 .md 或 .markdown，调整顺序、预览，再导出带逐篇书签的 A4 PDF。合并上限为 100 页、64 MiB。在权限和大小限制内嵌入本地相对路径图片；缺失、远程或越界图片显示占位提示。原文件保持不变。

Markdown 阅读外观

选择跟随系统、浅色、深色或暖纸色主题，以及字体、字号、间距和阅读宽度。

OnePreview App · Markdown → PDF

在 App 内导入 Markdown，导出报告 PDF

在 Mac、iPhone 或 iPad 的 OnePreview 中，前往“文件 > 工具 > Markdown 转 PDF”，导入 .md 或 .markdown 文件。检查实际 A4 PDF 后再保存，支持表格、代码换行、Mermaid 流程图和 KaTeX 公式。PDF 导出属于主 App，不在 Finder 快速查看中提供。OnePreview 是查看器，不是编辑器。

工作流

为真实 Quick Look 使用习惯设计。

留在 Finder

macOS 中按空格键即可检查受支持文件，不必打开完整编辑器。

支持 iPhone 和 iPad

在“文件”App 中长按支持的文件，选择“打开方式”，再选择 OnePreview。普通点击可能会使用 Apple 内置预览。

内置启用指引

在 Mac 上启用快速查看扩展；在 iPhone 与 iPad 上从“文件”App 使用“打开方式”> OnePreview。

在 Mac 上选择常用编辑器

从 OnePreview 或 Finder 快速查看中，用常用编辑器打开原始文件。可按文件类型记住选择，不改变 macOS 默认打开方式。

查看启用帮助
无需账户安装一次，即可在本地查看文件。
本机预览只读预览，在设备本地处理文档内容。
免费使用提供 App Store 版本。

设置与预览指南

启用 Quick Look 扩展

安装后先打开 OnePreview，再到系统扩展设置中启用。
