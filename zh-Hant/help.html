OnePreview 說明

在 Mac 上啟用 Finder 快速查看；在 iPhone 與 iPad 上使用「檔案」App 的「開啟方式」。

在 App Store 下載

如何在 macOS 啟用 OnePreview？

安裝後打開一次 OnePreview。在 macOS Sequoia 中，前往「系統設定」>「一般」>「登入項目與擴充功能」>「Quick Look」並啟用 OnePreview。在 macOS Sonoma 中，使用「系統設定」>「隱私權與安全性」>「擴充功能」>「Quick Look」。

如何在 iPhone 或 iPad 使用 OnePreview？

在「檔案」App 中長按支援的檔案，選擇「開啟方式」，再選擇 OnePreview。一般點按可能會使用 Apple 內建預覽。

支援哪些檔案格式？

Markdown、MDX、TextBundle、TextPack、JSON、JSONL、YAML、XML、CSV、TSV、TOML、ENV、SQLite 資料庫、程式碼、純文字、日誌、資料夾、ZIP/TAR.GZ 壓縮檔與 Apple property list。

為什麼 Markdown 預覽有時會顯示舊版本？

macOS Quick Look 可能會快取預覽快照。關閉預覽後用空白鍵重新開啟；如果 Finder 在開發時仍顯示舊內容，可執行 qlmanage -r && qlmanage -r cache。

為什麼部分本機 Markdown 圖片沒有顯示？

Apple 沙盒規則會限制 Quick Look 擴充功能讀取所選檔案旁邊的其他檔案。網路圖片 URL 最可靠。

OnePreview 會編輯檔案嗎？

不會。OnePreview 是檢視器，不會修改你的文件。

OnePreview 為 macOS 提供 Finder 快速查看擴充功能，並為 iPhone 與 iPad 提供本機檔案檢視功能。
