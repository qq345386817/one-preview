Markdown 預覽

在 Mac Finder 中快速查看，或從 iPhone 與 iPad 的「檔案」App 開啟清楚的 Markdown。

GitHub 風格渲染

不用打開完整編輯器，就能預覽標題、表格、任務清單、程式碼區塊、提示與文件式 Markdown。

MDX、TextBundle、TextPack

將常見 Markdown 套件格式當成可閱讀文件開啟，而不是普通資料夾或壓縮檔。

內建 Mermaid 與 KaTeX

使用隨附資源渲染圖表、流程圖與數學公式，常見 Markdown 文件可離線預覽。

渲染或原始碼

需要檢查精確語法時，可在可讀 HTML 預覽與原始 Markdown 之間切換。

不只 Markdown

一個擴充功能，處理每天都會檢查的開發者檔案。

程式碼

Swift、Python、JavaScript、TypeScript、C、C++、Objective-C、Rust、Go、Ruby、Java、Shell、Assembly 等。

結構化資料

JSON、JSONL、YAML、XML、CSV、TSV、TOML、ENV、Apple property list 等文字資料格式。

壓縮檔與資料夾

瀏覽 ZIP/TAR.GZ 內容與資料夾列表，查看檔案大小、修改日期與清楚的結構。

SQLite 資料庫

不用先開資料庫工具，就能檢查資料表、視圖、索引、欄位與範例列。

技術格式： Markdown、MDX、TextBundle、TextPack、JSON、JSONL、YAML、XML、CSV、TSV、TOML、ENV、SQLite、Swift、Python、JavaScript、TypeScript、C、C++、Objective-C、Rust、Go、Ruby、Java、Shell、Assembly、原始碼、純文字、記錄、資料夾、ZIP/TAR.GZ 壓縮檔、Apple 屬性列表（plist）。

工作流程

為真正的 Quick Look 習慣設計。

留在 Finder

在 macOS 按空白鍵即可檢查支援檔案，不必啟動完整編輯器。

支援 iPhone 與 iPad

在「檔案」App 中長按支援的檔案，選擇「開啟方式」，再選擇 OnePreview。一般點按可能會使用 Apple 內建預覽。

包含設定指引

在 Mac 上啟用快速查看擴充功能；在 iPhone 與 iPad 上從「檔案」App 使用「開啟方式」> OnePreview。

閱讀設定說明

設定與檔案預覽指南

啟用 Quick Look 擴充功能

安裝後打開一次 OnePreview，然後在系統擴充功能設定中啟用。

了解隱私與檔案處理

檔案透過 Apple 系統預覽機制在本機預覽。

回報無法正確預覽的檔案

請提供檔案類型、作業系統版本與簡短重現步驟。

Markdown → PDF

免費線上 Markdown 轉 PDF，在瀏覽器中完成

將專案週報、技術文件和交付說明排成 A4 PDF。網頁轉換工具可獨立使用，不需安裝 OnePreview App。

不需安裝或上傳文件

開啟 .md、.markdown 檔案，或直接貼上內容。文件與所選圖片在目前瀏覽器工作階段中處理，不需帳號或 App。

保留表格、流程圖與公式

先檢查 A4 分頁、跨頁標題列、換行程式碼、Mermaid 流程圖與 KaTeX 公式，再透過「列印 / 儲存為 PDF」匯出。
