OnePreview 1.5.1 功能

連續閱讀、搜尋和匯出 Markdown 資料夾

資料夾連續閱讀與搜尋

在 OnePreview 開啟檔案夾、切換文件、跟隨 Markdown 相對連結與標題跳轉，並透過上一頁、下一頁回到閱讀位置。閱讀模式和位置保留於目前工作階段。可搜尋授權目錄內的檔名與可讀文字；達到掃描上限時會提示部分結果，不在磁碟儲存搜尋索引。

合併為帶書籤的 PDF

在主 App 從已開啟的檔案夾及子目錄選取最多 20 份 .md 或 .markdown，調整順序、預覽，再匯出附有逐篇書籤的 A4 PDF。合併上限為 100 頁、64 MiB。在權限與大小限制內嵌入本機相對路徑圖片；缺失、遠端或越界圖片顯示預留位置提示。原始檔案維持不變。

Markdown 閱讀外觀

選擇跟隨系統、淺色、深色或暖紙色主題，以及字體、字級、間距和閱讀寬度。

Markdown 預覽

Markdown， 不只是純文字。

GitHub 風格渲染

不用打開完整編輯器，就能預覽標題、表格、任務清單、程式碼區塊、提示與文件式 Markdown。

MDX、TextBundle、TextPack

將常見 Markdown 套件格式當成可閱讀文件開啟，而不是普通資料夾或壓縮檔。

內建 Mermaid 與 KaTeX

使用隨附資源渲染圖表、流程圖與數學公式，常見 Markdown 文件可離線預覽。

渲染或原始碼

需要檢查精確語法時，可在可讀 HTML 預覽與原始 Markdown 之間切換。

不只 Markdown

閱讀文件、檢查資料、查看壓縮檔目錄。

程式碼

Swift、Python、JavaScript、TypeScript、C、C++、Objective-C、Rust、Go、Ruby、Java、Shell、Assembly 等。

結構化資料

JSON、JSONL/NDJSON、YAML、XML、CSV、TSV、TOML、ENV, INI, properties、Apple property list 等文字資料格式。

壓縮檔與資料夾

瀏覽 ZIP/TAR.GZ/TGZ 內容與資料夾列表，查看檔案大小、修改日期與清楚的結構。

SQLite 資料庫

不用先開資料庫工具，就能檢查資料表、視圖、索引、欄位與範例列。

技術格式： Markdown、MDX、TextBundle、TextPack、JSON、JSONL/NDJSON、YAML、XML、CSV、TSV、TOML、ENV, INI, properties、SQLite、Swift、Python、JavaScript、TypeScript、C、C++、Objective-C、Rust、Go、Ruby、Java、Shell、Assembly、原始碼、純文字、記錄、資料夾、ZIP/TAR.GZ/TGZ 壓縮檔、Apple 屬性列表（plist）。

OnePreview App · Markdown → PDF

在 App 內匯入 Markdown，匯出報告 PDF

在 Mac、iPhone 或 iPad 的 OnePreview 中，前往「檔案 > 工具 > Markdown 轉 PDF」，匯入 .md 或 .markdown 檔案。檢查實際 A4 PDF 後再儲存，支援表格、程式碼換行、Mermaid 流程圖與 KaTeX 公式。PDF 匯出屬於主 App，不在 Finder 快速查看中提供。OnePreview 是檢視器，不是編輯器。

工作流程

為真正的 Quick Look 習慣設計。

留在 Finder

在 macOS 按空白鍵即可檢查支援檔案，不必啟動完整編輯器。

支援 iPhone 與 iPad

在「檔案」App 中長按支援的檔案，選擇「開啟方式」，再選擇 OnePreview。一般點按可能會使用 Apple 內建預覽。

包含設定指引

在 Mac 上啟用快速查看擴充功能；在 iPhone 與 iPad 上從「檔案」App 使用「開啟方式」> OnePreview。

在 Mac 上選擇常用編輯器

從 OnePreview 或 Finder 快速查看中，用常用編輯器打開原始檔案。可依檔案類型記住選擇，不變更 macOS 預設打開方式。
