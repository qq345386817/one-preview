    清晰排版，文字仍可複製

    PDF 保留文件文字，而非文件的螢幕截圖。支援標準 Markdown、GitHub 風格表格、程式碼區塊、Mermaid 流程圖和 KaTeX 數學公式。長表格跨頁時重複標題列，長程式碼依頁面寬度換行。

    如何儲存 PDF？

    點選「列印 / 儲存為 PDF」，在瀏覽器或系統列印介面選擇 PDF 儲存方式。iPhone 和 iPad 可從系統列印預覽分享或儲存 PDF。這裡的預覽顯示報告內容，附加頁首、頁尾與紙張設定由列印介面控制。

    有哪些限制？

    一種 A4 版面，Markdown 不超過 500 KB，報告不超過 100 頁。表格單列過高或元素無法安全分割時會明確提示，避免產生截斷的 PDF。缺少圖片、無效流程圖或公式也會提示。首期不支援 MDX 元件、自訂指令碼以及 TextBundle、TextPack 套件。

    這個 Markdown 轉 PDF 工具免費嗎？

    是的，目前網頁工具免費使用，不需要帳號或 OnePreview App。文件內容和所選圖片僅保留在目前瀏覽器工作階段中，不會上傳至轉換伺服器。

    能將 Mermaid 流程圖和數學公式匯出至 PDF 嗎？

    可以。在 mermaid 圍欄程式碼區塊中編寫圖表，並使用相容 KaTeX 的語法輸入公式。列印前請檢查預覽。圖表或公式無法呈現時，工具會顯示提示並保留原文，不會直接省略內容。

    Markdown 表格如何跨頁顯示？

    GitHub 風格的 Markdown 表格會依 A4 頁面分頁，並在續頁重複標題列。程式碼會依可用寬度換行。若表格單列過高或內容仍超出頁寬，工具會明確提示，請縮短該列或減少欄數後重試。

    為什麼 PDF 中的圖片沒有顯示？

    請另外選擇 Markdown 引用的本機圖片，並確保檔名相符。工具不會自動載入遠端圖片。最多選擇 16 張，每張不超過 5 MB，總大小不超過 20 MB；缺少或無法讀取的圖片會顯示提示。

    還需要預覽本機檔案？

    OnePreview App 可在 Mac、iPhone 和 iPad 上預覽 Markdown 和開發者檔案。網頁工具可獨立使用，不需安裝 App。
